# Desain UI

Halaman web menggunakan tema terang bergaya Google dengan latar putih, teks abu lembut, aksen biru, sudut membulat, dan kartu putih. Terdapat dua tab: **Subnet** dan **VLSM**.

Bagian Subnet berisi input IP, prefix, tombol Hitung, kartu ringkasan, dan pesan error. Bagian VLSM berisi input CIDR jaringan, daftar kebutuhan yang dapat ditambah atau dihapus, tabel hasil, dan pesan error.

Layout responsif untuk desktop dan mobile. Ketiga keadaan UI tersedia: kosong, hasil berhasil, dan error.
