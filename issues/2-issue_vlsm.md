# Deskripsi
Tambahkan fitur alokasi VLSM pada kalkulator subnet IPv4.

# Tugas
- Implementasikan `alokasi_vlsm`.
- Tambahkan `POST /api/vlsm`.
- Hubungkan tab VLSM pada halaman web.
- Tambahkan test VLSM.

# Kriteria Penerimaan
- Kebutuhan diurutkan terbesar terlebih dahulu.
- Contoh kebutuhan 100, 50, 20, 2 menghasilkan CIDR yang ditetapkan SPEC.
- Jaringan tidak cukup dan input invalid ditolak dengan HTTP 400.
